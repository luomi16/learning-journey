## Purpose
Replace this sentence with the question or idea this note explores. Keep the daily timeline brief and use this page for the explanation you want to revisit later.

## Detailed takeaways
- Explain a result or method in your own words.
- State the assumptions it relies on.
- Distinguish what the source establishes from your own interpretation.

## Connections
Connect a relevant keyword to a [knowledge page](knowledge/template-concept). Explain how this reading supports, extends, or challenges an earlier idea rather than only collecting links.

Use `[note title](notes/your-note-name)` to reference an existing note. Create the target file before adding the link.

## Outputs
Describe what you made or clarified. Add a real link when a notebook, experiment, diagram, or write-up is ready. Remove this section when there is no output to record.

## Open questions
Write the points you still need to check. Include a concrete next action that would help resolve each question.

## Reuse this page
Copy templates/note.md to notes/your-note-name.md, update its title, and write your content. A note gets its own address and appears in Notes without creating another timeline card.

Link it from a day's Outputs with `[Research notes](notes/your-note-name)`. See [the daily writing guide](notes/2026-11-20-template-paper-a) for the complete workflow.

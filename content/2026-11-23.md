#### Paper
[EdgeShard: Efficient LLM Inference via Collaborative Edge Computing](https://doi.org/10.1109/JIOT.2024.3524255)
Authors: Mingjin Zhang, Xiaoming Shen, Jiannong Cao, Zeyang Cui, Shan Jiang
Published: May 2025

#### Takeaways
- EdgeShard splits a chosen LLM into layer blocks that run across selected edge devices and cloud servers.
- Offline profiling estimates layer execution time, memory use, and activation size. Link bandwidth determines the cost of transferring activations between devices.
- Dynamic programming jointly chooses participating devices and assigns layers while respecting device memory limits.
- The latency objective minimizes total computation and communication time. The throughput objective reduces the time of the slowest pipeline stage.
- On a heterogeneous Llama 2 testbed, the authors report up to 50% lower latency and twice the throughput of their baselines.
